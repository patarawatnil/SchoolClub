# SchoolClub

SchoolClub is a web application developed using Spring Boot as part of an academic project. The application provides basic user management functionality, including user registration, login, logout, and displaying a list of registered users.

The project was created to practice web application development, database integration, and basic user authentication using the Spring Boot framework.

## Features

- **User Registration** – Allows new users to register an account.
- **User Login** – Allows registered users to log in to the application.
- **User List** – Displays a list of registered users.
- **User Logout** – Allows logged-in users to log out of the application.

## Technologies Used

- **Java** – Programming language
- **Spring Boot** – Backend application framework
- **Thymeleaf** – Server-side template engine for rendering web pages
- **MySQL** – Relational database management system

## Project Overview

SchoolClub follows a basic web application architecture, using Spring Boot to handle application logic and database operations, Thymeleaf to render the user interface, and MySQL to store user information.

The main focus of this project is implementing basic user management and connecting a web application to a relational database.

## Project Scope

This project was developed as an academic exercise with a focus on fundamental web application features. Its functionality is intentionally limited to the core requirements of the original assignment.
